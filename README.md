# 診察メモ

通院記録を構造化して管理するシングルページWebアプリです。

## 機能

- **メモ管理** — 診察日ごとに「精神状態」「医師との会話」「課題・振り返り」を記録
- **カレンダー表示** — 月単位で受診日を一覧。病院ごとに色分けして表示
- **病院登録** — 病院名・診療科・カラーを登録してメモにタグ付け
- **AIから自動入力** — ChatGPT/Claude等で生成したテキストを貼り付けると、AnthropicのAPIが各項目に自動振り分け
- **CSVエクスポート** — 全期間または期間指定でデータをダウンロード

## 使い方

1. ブラウザで `index.html` を開く（またはGitHub Pagesの公開URLにアクセス）
2. データはブラウザの `localStorage` に保存されます
3. AIから自動入力を使うには「設定 → AI設定」でAnthropicのAPIキーを登録してください

## GitHub Pages でのデプロイ

このリポジトリをGitHub Pagesで公開すると、どのデバイスのブラウザからもアクセスできます。  
ただしデータは各端末のブラウザにローカル保存されるため、端末間での同期はされません。
